# LITTIT Dataset

**LITTIT: @LLM, I Think This Is True**

LITTIT is a dataset designed for studying the robustness of Large Language Models (LLMs) against deliberately confusing or adversarially constructed fake-news content.

The dataset focuses on evaluating whether LLMs can reliably distinguish between true and false information when additional misleading or confusing elements are introduced.

## Dataset Status

> **Note:** The research paper associated with this dataset has **not yet been formally published**. The corresponding manuscript is currently under preparation / submission.

Therefore, please refer to this repository and the dataset itself when citing or acknowledging the dataset until the associated paper is officially published.

## Dataset Description

LITTIT is constructed for research on:

* Fake news detection
* LLM robustness
* Adversarial information
* Confusing or misleading textual content
* LLM-based fact verification
* Reliability of large language models in distinguishing true and false information

The dataset contains processed data intended for research and evaluation purposes.

The original source information and identifying features have been removed or processed during dataset construction and cleaning.

## Ethical Considerations

This dataset is intended to support research into the reliability and robustness of LLMs when processing potentially misleading information.

The inclusion of false or misleading content in this dataset does **not** constitute an endorsement of such content.

Researchers should avoid presenting individual samples as factual information without appropriate verification and context.
